# Map Fountain — Release Status

## Current state

**Router-only Map Fountain is an architecture/workflow, not a field GIS-server software release.**

Current accepted field chain:

```text
USB SSD
→ GL.iNet Flint 2
→ Samba / SMB
→ Wi-Fi or Ethernet
→ ArcGIS Earth
→ native TPKX
```

Windows ArcGIS Earth direct network-hosted TPKX over Wi-Fi is **LIVE-PROVEN**.

The next acceptance gate is **ArcGIS Earth Mobile on the router-only architecture**.

## Historical software build

`Rasta USB Map Fountain v0.2.1 TEST` was a 2026-08-16 Windows-hosted HTTPS WMTS experiment. It remains important engineering history but is **not the current field architecture or current release candidate**.

## Current public-release boundary

There is no claim that a packaged Map Fountain application is required for the proven Windows field path. The current public deliverable is the documented architecture, acceptance evidence, operator workflow, and map-manufacturing ecosystem.

A future **Feeder** utility may become a normal software release after its need and workflow are proven.

Do not label the historical Windows WMTS source snapshot as the current Map Fountain product.
