## Before a normal release

Required gates:

1. general HTTPS certificate/IP lifecycle;
2. cold restart/reconnect acceptance;
3. repeatable large-map session;
4. clean Windows packaging;
5. final operator documentation;
6. exact release artifact preserved and hashed.

Do not silently label the current source snapshot as a finished consumer release.
